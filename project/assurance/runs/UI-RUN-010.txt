Found and fixed during the run (the first run had 0 violations but these were visible in the screenshots)
  1. Petal's text inputs and selects had no border width and no padding: they assume @tailwindcss/forms, which
     Petal's UPGRADE_GUIDE shows and the installed rules.md omits. Enabled (bundled in the standalone Tailwind
     binary; no package added).
  2. Petal's control edge is gray-300, 1.4:1 on white; overridden with DIR-001's control border (above).
  3. Alerts and badges used Petal's default "light" variant, which stays light in dark mode; now "soft".
  4. At 390 px the header badge ran off the right edge (now wraps) and the table overflowed its card (now
     scrolls sideways in a region with tabindex 0, role region, and a label; axe's scrollable-region-focusable
     caught the first version).
  5. Amounts were left-aligned under a right-aligned header while the caption said they line up on the right;
     the column's class reached only the header (Petal's row_class is for cells).
  6. The container's fontconfig resolved sans-serif and system-ui to Liberation Mono; fonts-dejavu-core added to
     the container and .devcontainer/Dockerfile.
