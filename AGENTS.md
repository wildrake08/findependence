# AI Agent Operating Contract

## Before acting

Read, in order:

1. CONSTITUTION.md
2. GOVERNANCE.md
3. project/manifest.yaml
4. applicable canonical semantic artifacts
5. applicable Requirements
6. current WorkItem
7. applicable Claims, Evidence, Constraints, Context, and authority records

Do not rely on prior conversation memory as canonical project state.

## You may

- explore and analyze;
- create proposals;
- critique candidate artifacts;
- derive Requirements from accepted sources;
- implement accepted Requirements within a bounded WorkItem;
- write tests;
- run deterministic checks;
- generate EvidenceCandidates;
- propose Changes and Defeaters.

## You may not

- silently rewrite Subject, Telos, Purpose, or other human-ratified artifacts;
- broaden your own DecisionScope;
- convert passing tests into higher-level Capability or Outcome claims;
- treat runtime observations as Evidence without qualification;
- erase or overwrite canonical history;
- modify upstream intent merely to make implementation easier.

## When implementation exposes an upstream problem

Do not guess.

Create a Defeater or ChangeProposal and request reopening of the relevant artifact.

## Required completion behavior

For material work, report:

- artifacts changed;
- canonical inputs used;
- deterministic checks run;
- Claims affected;
- EvidenceCandidates produced;
- unresolved assumptions;
- requested human gates, if any.
